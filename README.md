# Laboratorio 1 - Aplicaciones Web

Este repositorio contiene los archivos y enlaces necesarios para preparar el entorno antes de realizar el Laboratorio 1.

Antes del laboratorio, deben descargar e instalar los siguientes componentes.

## 1. Java SE 21

Descargar e instalar **[JDK 21](https://www.oracle.com/java/technologies/javase/jdk21-archive-downloads.html)**.

------------------------------------------------------------------------

## 2. Eclipse IDE

Descargar e instalar **[Eclipse IDE for Enterprise Java and Web Developers](https://www.eclipse.org/downloads/)**.

------------------------------------------------------------------------

## 3. Servidor web: Apache Tomcat 11

Descargar **[Apache Tomcat 11](https://tomcat.apache.org/download-11.cgi)** y descomprimirlo en una carpeta de su preferencia.

------------------------------------------------------------------------

## 4. Librerías JSTL

Descargar las siguientes dos librerías:

- **[JSTL API](https://repo1.maven.org/maven2/jakarta/servlet/jsp/jstl/jakarta.servlet.jsp.jstl-api/3.0.0/jakarta.servlet.jsp.jstl-api-3.0.0.jar)**
- **[JSTL Implementation](https://repo1.maven.org/maven2/org/glassfish/web/jakarta.servlet.jsp.jstl/3.0.1/jakarta.servlet.jsp.jstl-3.0.1.jar)**

Conservar ambos archivos `.jar`.

------------------------------------------------------------------------

## 5. Base de datos: MySQL Server (incluyendo MySQL Workbench)

Descargar e instalar **[MySQL Server 8.0](https://dev.mysql.com/downloads/windows/installer/8.0.html)**.

Durante la instalación deberán configurar una contraseña para el usuario de MySQL. **Recuerden esta contraseña, ya que será utilizada durante el laboratorio.**

------------------------------------------------------------------------

## 6. MySQL Connector/J

Descargar **[MySQL Connector/J](https://dev.mysql.com/downloads/connector/j/)**.

Conservar el archivo `.jar`, ya que lo utilizaremos para conectar nuestra aplicación Java con MySQL.

------------------------------------------------------------------------

## Antes del laboratorio

Verifiquen que tengan instalado / configurado:

-   [ ] JDK 21
-   [ ] Eclipse IDE for Enterprise Java and Web Developers
-   [ ] MySQL Server 8.0
-   [ ] MySQL Workbench

Y que tengan descargado:
-   [ ] Apache Tomcat 11
-   [ ] JSTL API
-   [ ] JSTL Implementation
-   [ ] MySQL Connector/J

Los pasos de instalación y configuración se encuentran explicados en los slides del curso.
